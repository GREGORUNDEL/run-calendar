# run-calendar

Календарь пробежек: каждая пробежка из Garmin Connect отмечается на календаре штампом с километрами. По нажатию на день видно дистанцию, время, темп, пульс и маршрут.

Сайт: https://gregorundel.github.io/run-calendar/

## Как это устроено

- `site/` — сама страница (GitHub Pages).
- `scripts/sync.py` — забирает пробежки через Garmin Connect Personal API и складывает их в `site/data/`.
- `.github/workflows/sync.yml` — запускает синхронизацию по кнопке на странице и обновляет сайт.

Маршруты хранятся упрощёнными, первые и последние 300 м каждого маршрута обрезаются.

## Секреты и токены

- `GARMIN_API_KEY` — секрет репозитория (Settings → Secrets and variables → Actions). Ключ живёт до года, потом его нужно создать заново в Garmin Connect и обновить секрет.
- Кнопка синхронизации использует fine-grained токен GitHub с одним правом: Actions (read and write) для этого репозитория. Токен хранится только в браузере на телефоне.

## Полная перезагрузка

Actions → Sync and deploy → Run workflow → отметить «Перезагрузить всю историю пробежек».
